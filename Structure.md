# Structure

## Files structure

```text
data/                          # Все данные пользователя
├── persistent/                # Важные данные для переноса между ПК
│   └── configs/               # Основное хранилище конфигов
│       ├── .zshrc             # Исходный конфиг, остальные пути - symlinks
└── recoverable/               # Данные, которые можно восстановить
    └── projects/              # Git-репозитории и другие восстанавливаемые файлы
```

## Programs

Стараемся использовать веб версии вместо отдельных программ, потому что

  1. Засоряют диск
  2. Создают фоновую нагрузку
  3. Больше программ -> больше контекст -> больше визуальная нагрузка

Для нативных программ используем только там, где реально требуется нативность, типа Telegram, VSCode

Если программу пришлось удалить, то от нее останется куча мусора в любой ОС

!!! Никогда не использовать `rm -rf`, кроме удаления `node_modules`, `package-lock.json`

```bash
trash # Удаление файла
```
